## ADDED Requirements

### Requirement: 新建轮轴基础信息录入

系统 SHALL 支持通过录入表单创建一根新轮轴，可录入字段与 `prototype/axle-new.html` 一致：车型、车号、修程、轴位、左右侧、轴承型号、生产厂家、生产日期、钢号/材质、出厂编号、合格证编号、装机日期、公称轮径、实测轮径、轴颈直径、轮缘厚度、轮辋厚度、轮对内侧距、备注。其中车型、车号、修程、轴位、生产厂家、生产日期、公称轮径、实测轮径为必填项。

#### Scenario: 成功创建轮轴
- **GIVEN** 用户已打开「新建轮轴」页面，并填写了全部必填字段
- **WHEN** 用户提交表单
- **THEN** 系统生成全局唯一轮轴 ID 并保存该轮轴，初始生命周期状态为「在役」，写入一条「生产出厂登记」履历，并返回新建轮轴的信息；该轮轴随后可通过列表与详情接口查询到

#### Scenario: 只填必填项、留空可选字段
- **GIVEN** 用户填写了全部必填字段，但留空部分可选字段（如轴承型号、出厂编号、合格证编号、装机日期、备注等）
- **WHEN** 用户提交表单
- **THEN** 系统仍创建轮轴，留空的可选字段按空值保存

### Requirement: 新建轮轴必填校验

系统 SHALL 在创建轮轴时校验必填字段，任一必填字段缺失时 SHALL 拒绝创建，并明确提示缺失的字段。

#### Scenario: 缺失必填字段
- **GIVEN** 用户打开「新建轮轴」页面
- **WHEN** 用户未填写任一必填字段（车型、车号、修程、轴位、生产厂家、生产日期、公称轮径、实测轮径中的任意一个）就提交
- **THEN** 系统拒绝创建、不生成轮轴，并提示缺失的必填字段

### Requirement: 新建轮轴唯一标识

系统 SHALL 在新建轮轴时由服务端生成全局唯一 ID，格式为 `AX-YYYYMMDD-NNN`（如 `AX-20261007-018`），与系统中已有轮轴的 ID 不重复。

#### Scenario: 连续创建不重复
- **GIVEN** 系统中已存在多根轮轴
- **WHEN** 连续创建多根新轮轴
- **THEN** 每根轮轴的 ID 互不重复，且均符合 `AX-YYYYMMDD-NNN` 格式

### Requirement: 修程取值扩展

系统 SHALL 支持修程字段取「例行 / 中修 / 大修 / 复检」四个值；表单中的「例行检查」SHALL 归一为「例行」。

#### Scenario: 选择各修程
- **GIVEN** 用户打开「新建轮轴」页面
- **WHEN** 用户分别以「例行 / 中修 / 大修 / 复检」作为修程提交（含以「例行检查」作为修程提交）
- **THEN** 系统保存对应的修程值，其中「例行检查」按「例行」保存
